# Morris Cloud Wiki

This is our family's instruction manual for the computer systems at home:
where our photos and files are kept, how they're protected, and **what to do
if something goes wrong**.

It's written so that anyone in the family can follow it, not just Tony.
Where a page has to use a technical term, it's explained on the page or in
the [Glossary](glossary.md).

!!! warning "If something is broken right now"
    1. **Don't delete, reset, or "clean up" anything yet.** Most problems can
       be undone if nothing else has been changed.
    2. Find the page for the thing that's broken in the menu on the left.
       Each page has a section for "When something goes wrong."
    3. You'll need passwords for some steps. **Passwords are never written in
       this wiki.** Each page tells you the *name* of the entry to look up in
       the family password manager.
    4. If you're stuck, it's okay to hand a page to a tech-savvy friend.
       These pages are written so they can follow them too.

## How to open this wiki

The wiki is private. Only family members whose email addresses are on the
approved list can read it.

1. Go to **wiki.morriscloud.com**.
2. You'll see a Cloudflare sign-in page. Type your email address and choose
   to receive a code.
3. Check your email for a message from Cloudflare with a short code. Type it
   in.
4. You're in. You'll stay signed in on that device for about a month.

If no code arrives, your email address probably isn't on the approved list.
See [Wiki hosting → If you can't get in](infrastructure/wiki-hosting.md#if-you-cant-get-in).
